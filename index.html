Contamination pipeline results

This page accompanies the MSc thesis Assessing Data Contamination Risk In Proprietary LLMs: A Reproducible Black-Box Detection Pipeline (NOVA IMS, 2026). It collects the current assessment reports, pipeline documentation, reproducibility data, and run artefacts for the active XSum and BBC2025 benchmark studies.
